# University-Student-Campus-System
University Student Record and Campus Route Management System - CIT300

## CIT300 Data Structures and Algorithms 

This project is a Java console-based application developed for managing university student records and representing campus locations and connections.

## Main Features

1. Add Student Record
2. Update Student Record
3. Delete Student Record
4. Display All Student Records
5. Add Service Request
6. Process Service Request
7. Display Recent Actions
8. Display Students using BST
9. Search Student using Hashing
10. Add Campus Location
11. Remove Campus Location
12. Add Campus Connection
13. Remove Campus Connection
14. Display Campus Connections
15. BFS/DFS Campus Traversal
16. Exit
